Day 1

9/10 週四｜抵達神戶 + Harborland 輕鬆夜景

  1. 08:45台中機場起飛搭乘 JX306 前往神戶機場。
  2. 12:30抵達神戶機場抓入境、領行李、集合與小孩整理時間。Google Maps
  3. 13:30前往 Town House Sannomiya East建議 Port Liner 到三宮後短程計程車，或三組家庭分車直達。Google Maps
  4. 15:00入住、補眠、採買附近先買水、早餐、尿布備品和簡單零食。Google Maps
  5. 17:00Harborland / umie / MOSAIC晚餐、港邊散步、摩天輪，作為第一天的放鬆開場。Google Maps
  6. 20:00回飯店第一晚以早睡為目標，讓孩子調整節奏。

注意事項

神戶動物王國常見週四休園，這天不排大景點。抵達日最重要的是降低疲勞，不要把港邊行程排成必須完成的任務。

Day 2

9/11 週五｜神戶動物王國 + 南京町

  1. 08:00早餐與出門準備推車、替換衣物、濕紙巾和輕食先備好。
  2. 09:20前往 Port Liner 三宮站搭往計算科學中心站方向，動物王國就在站邊。
  3. 10:00神戶動物王國先看室內區與動物互動，天氣熱或下雨也比較穩。Google Maps
  4. 12:00園內午餐不要把午餐拖太晚，幼兒下午情緒會比較穩。
  5. 14:30回飯店午睡搭 Port Liner 回三宮，再回住宿休息。Google Maps
  6. 16:30南京町邊走邊吃，順逛元町商店街、舊居留地、大丸神戶店周邊。Google Maps
  7. 18:30晚餐與回飯店若南京町太擠，就轉往元町或三宮找能坐下來的餐廳。

注意事項

南京町放週五傍晚最順，也避開週六人潮。這天有兩段移動，下午午睡請不要省略，後面三天會比較好走。

Day 3

9/12 週六｜麵包超人博物館 + 神戶須磨海洋世界

  1. 08:30早餐後出門週六人潮較多，麵包超人館建議買早場指定票。
  2. 10:00神戶麵包超人兒童博物館短版抓 1.5 到 2 小時，2F 博物館區不可使用嬰兒車，建議準備揹巾。Google Maps
  3. 12:00MOSAIC / umie 午餐先吃飽再移動，下午才有體力去須磨。Google Maps
  4. 13:15移動到須磨海浜公園從神戶站或三宮搭 JR 到須磨海浜公園站，出站後步行約 5 分鐘。Google Maps
  5. 14:00神戶須磨海洋世界看虎鯨、海豚、水族館展區；官方建議事前購票，最後入館是閉館前 1 小時。Google Maps
  6. 17:00回三宮晚餐如果小孩太累，提早離開回住宿休息，不硬等到閉館。

注意事項

這天排得下，但比原版更滿。若孩子前一天睡不好，建議二選一：想要室內水族館與大型表演就選須磨海洋世界，想要角色互動就選麵包超人館。

Day 4

9/13 週日｜淡路島蠟筆小新 Adventure Park

  1. 08:00取車與出發準備建議三宮附近取車，確認兒童安全座椅、ETC、停車場位置。Google Maps
  2. 09:00開車前往淡路島經明石海峽大橋，車上準備零食與安撫用品。Google Maps
  3. 10:15Nijigen no Mori以 Crayon Shin-chan Adventure Park 為主，拍照與幼兒可玩的區域優先。Google Maps
  4. 12:00園區或服務區午餐不要貪多跑點，午餐後讓孩子有安靜時間。
  5. 13:30園區散步、商店、照片時間若孩子累，就提早收尾，不硬排夜間活動。
  6. 15:30回神戶避開太晚回程，晚上在飯店附近吃飯。
  7. 18:30還車與晚餐行李留飯店，只做單日租車，壓力最低。

注意事項

這是全程最適合租車的一天。若改搭大眾運輸也可行，但班次與轉乘容錯率較低，三個幼兒同行會比較辛苦。

Day 5

9/14 週一｜退房 + 神戶機場返台

  1. 07:30早餐與整理行李把登機用品、尿布、備用衣物放在隨身包。
  2. 09:30退房不再排景點，只保留附近早餐、便利商店、伴手禮時間。
  3. 10:00前往神戶機場從三宮搭 Port Liner 最直覺；行李多可分車搭計程車。Google Maps
  4. 11:00機場報到與午餐帶小孩抓寬一點，安檢前後都保留緩衝。Google Maps
  5. 13:30神戶機場起飛搭乘 JX307 返台，15:35 抵達台中。Google Maps

注意事項

最後一天不要臨時加景點。三組家庭只要有人行李或小孩狀態卡住，壓線壓力會很大，早到機場會舒服很多。
